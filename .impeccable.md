# Skynet — Design Context

> Captured via `/impeccable teach` (codebase extraction + founder interview). Source of design truth for all `/impeccable`, `/shape`, and craft work. Update the sections in place as the product evolves.

## Design Context

### Users
Practitioners who optimize LLM prompts/programs with Skynet (a DSPy-as-a-service platform). They submit "optimization jobs" that fan out into many LLM calls (a task model + a reflection model iterating) to auto-improve prompts. Audience skews technical (ML/AI engineers, prompt engineers, applied researchers) but the product deliberately offers a "lite" mode for less-technical users alongside "advanced." Sessions are focused and intentional — people run real, sometimes expensive workloads and watch results. The app is **RTL-first** (Hebrew origin) and now localized across **24 locales** (incl. Hebrew, Arabic, Persian RTL).

### Brand Personality
Calm, trustworthy, craft-premium. Not loud, not "techy-neon." It reads like a refined professional instrument — warm rather than clinical. Three words: **warm, precise, premium.** Emotional goal: confidence and control over something powerful (and, soon, something the user pays real money to run) — never anxiety or hype.

### Aesthetic Direction
- **Theme: light.** Warm, earthy, editorial-leaning. Used in focused work sessions, not a dark "trading terminal."
- **Palette (existing tokens):** cream background `#faf8f5`, espresso foreground/primary `#1c1612` / `#3d2e22`, warm-beige accent `#ede7dd`, taupe muted-foreground `#8c7a6b`, sand borders `#ddd6cc`, sidebar `#f5f1ec`. Signature **gold accent `#C8A882`** used sparingly for focus rings and active/selected affordances (the "10%" accent). Cards are near-white `#ffffff` on cream.
- **Type:** Inter (Latin UI/body) + Heebo (Hebrew), both variable, with `@font-face` subsets preloaded. (Inter is pre-existing product canon — keep it for consistency; do **not** swap fonts for new surfaces.)
- **Stack:** Next.js App Router, shadcn/ui + Radix primitives, Tailwind v4 (`@theme` tokens, semantic color vars), Framer Motion for orchestrated entrances. Tooltips/popovers/tabs already standardized.
- **Anti-references:** the AI-slop palette (cyan-on-dark, purple→blue gradients, neon glow), gradient text, side-stripe accent borders, card-in-card nesting, undifferentiated icon-topped card grids. None of these fit Skynet's warm/refined voice.

### Design Principles
1. **Direction-aware by construction.** Every surface uses logical CSS (inline-start/end), mirrors correctly in RTL, and pulls copy from the i18n layer (`msg()` / `TERMS`) — never hardcoded English. New money/credit copy must be translatable across all 24 locales.
2. **Warm minimalism, gold used rarely.** Lean on the cream/espresso/taupe neutrals for structure; spend the `#C8A882` gold only on the one thing that matters in a view (active state, primary affordance, "you are here").
3. **Trust through transparency.** This product spends the user's money. Always show cost before commitment (per-job credit estimate) and after (actual). No hidden burn, no surprise. Calm, factual microcopy over salesy urgency.
4. **Progressive disclosure.** Lite vs advanced is core. Surface the simple path first (a balance, a "run" button), reveal the credit/model/BYOK machinery on demand — match the existing Settings-tabs + modal patterns rather than inventing new chrome.
5. **Extend, don't reinvent.** Reuse the established component vocabulary (SettingsRow, Tabs, Popover, TooltipButton, the shell header slot) so monetization feels native, not bolted on.
